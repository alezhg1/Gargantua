# Журнал изменений

Все существенные изменения в проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Семантического версионирования](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-29

### Добавлено

- **Симуляция чёрной дыры** (`gargantua.html`)
  - Реализация метрики Шварцшильда
  - Интегрирование геодезических методом Рунге-Кутты 4-го порядка
  - Адаптивная трассировка лучей (350 шагов на луч)
  - Визуализация гравитационного линзирования
  - Рендеринг аккреционного диска с релятивистскими эффектами
  - Интерактивное управление камерой (перетаскивание мышью, масштабирование колесом)
  - Производительность в реальном времени (~60 FPS)
  
- **Главная страница** (`main_page.html`)
  - Типографика в стиле NASA
  - 3D фон с Землёй (Three.js)
  - Адаптивный UI с эффектом матового стекла (glass-morphism)
  - Отображение статистики (Масса, Шаги лучей, Радиус ISCO)


### Технические особенности

- Графический конвейер WebGL 2.0
- Библиотека Three.js r128
- Пользовательские шейдерные программы для гравитационных эффектов
- Адаптивный контроль размера шага для численного интегрирования
- Процедурная генерация текстур (без внешних зависимостей)
- Адаптивный дизайн для всех размеров экранов
- Интеграция шрифта NASA

### Физическая реализация

- Метрика Шварцшильда
- Уравнения геодезических решены методом RK4
- ISCO (Внутренняя устойчивая круговая орбита) на 3.0 R_s
- Расстояние наблюдателя: 10.0 R_s
- Масса чёрной дыры: 4.3 × 10⁶ M☉ (параметры Стрельца A*)

### Производительность

- 350 адаптивных шагов трассировки лучей
- Целевая частота кадров 60 FPS
- Оптимизированный рендеринг WebGL
- Эффективное управление памятью
